# NK Feet

Website for NK Feet, a medical pedicure ("medische pedicure") practice in
Wijgmaal (Leuven), Belgium.

This site is a single static HTML page (`index.html`), hosted on GitHub Pages
under the custom domain [nk-feet.be](https://nk-feet.be).

## Structure

- `index.html` — the entire site: markup, styles, and structured data
  (JSON-LD) inline
- `favicon.svg` — browser tab icon (rose circle with "NK" monogram)
- `CNAME` — custom domain configuration for GitHub Pages (`nk-feet.be`)

## Analytics

Page views are tracked with [Umami](https://umami.is) via the script tag in
`index.html`.

## Local development

Just open `index.html` in a browser — no build step required.
